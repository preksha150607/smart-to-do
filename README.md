 # ⚡ Focus OS — Smart Daily Task Matrix

A clean, distraction-free productivity app designed around **cognitive energy** and **impact**, rather than endless, overwhelming checklists. Built with pure Python and [Streamlit](https://streamlit.io/).

---

## 💡 Why This Exists

Traditional to-do lists treat checking off "clean desk" with the same weight as "write pitch deck." 

**Focus OS** applies proven productivity frameworks:
- **⭐ Must-Win Daily Highlight:** Pick *one* needle-moving task per day.
- **⚡ Deep Work Blocks:** High-mental-effort tasks paired with time estimates.
- **🚀 Quick Wins (< 5 mins):** Batch low-friction tasks together to build momentum.
- **☕ Admin / Low Energy:** Reserved for your post-lunch slump.
- **⏳ Waiting On:** Track blockers and people you are waiting for replies from.

---

## ✨ Features

- **Linear / Notion Aesthetic:** Clean, typography-focused UI with distraction-free layout.
- **Dynamic Progress Bar:** Live completion percentage calculated automatically.
- **Time Estimation Badges:** Add expected time (`est: 45m`) to eliminate planning fallacy.
- **Interactive Checkboxes:** Strike-through styling and one-click task removal.
- **Responsive:** Works smoothly on desktop and mobile browsers.
